# 100 Python Questions

A growing collection of beginner-friendly Python programs covering basic input, calculations, conditionals, and standard library modules. The solutions are in the [`140_Questions`](./140_Questions/) folder.

## Contents

| File | Program |
| --- | --- |
| [`1.py`](./140_Questions/1.py) | Swap two variables |
| [`2.py`](./140_Questions/2.py) | Generate random integer and floating-point numbers |
| [`3.py`](./140_Questions/3.py) | Convert kilometers to miles |
| [`4.py`](./140_Questions/4.py) | Convert Celsius to Fahrenheit |
| [`5.py`](./140_Questions/5.py) | Display a month calendar |
| [`6.PY`](./140_Questions/6.PY) | Check whether a number is odd or even |
| [`7.py`](./140_Questions/7.py) | Check whether a year is a leap year |
| [`8.py`](./140_Questions/8.py) | Check whether a number is prime |

## Run a program

Use Python 3 and run a file from the repository root:

```bash
python 140_Questions/1.py
```

Programs that ask for values will prompt for input in the terminal. The random number and calendar examples use Python's built-in `random` and `calendar` modules; no third-party packages are needed.
